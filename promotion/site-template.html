A few things to know

Which devices and tags can I use?

You need an NFC-capable iPhone or Android device and a compatible tag. Available technologies and operations depend on the device, operating system, and tag.

What does the memory scan read?

Recognized NTAG213, NTAG215, and NTAG216 tags use model-specific page ranges. Other compatible Type 2 tags use a bounded scan of the data area declared by their Capability Container. Unreadable pages remain marked unavailable; an incomplete scan does not establish why access failed. The scan sends identification and read commands only, although tag-side read counters may advance.

Are these features in the store version?

This page showcases the current source and development build. Screenshots and newer features, including Flow Script, Type 2 Memory Scan, and the three-language interface, may differ from the app currently available in the stores. Check the store release notes or build from source for the corresponding version.
